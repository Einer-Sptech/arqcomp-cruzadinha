# Projeto Cruzadinha - Arquitetura Computacional

Jogo de cruzadinha interativo desenvolvido em HTML, CSS e JavaScript puro para a disciplina de Arquitetura Computacional da SPTECH. O projeto tem como objetivo fixar conceitos fundamentais de hardware e organização de computadores de forma lúdica.

## Funcionalidades
- Tabuleiro interativo com 12 palavras cruzadas entre si.
- Entrada direta de letras nas células do tabuleiro.
- Botão "Conferir Respostas" para validação automática.
- Contador dinâmico de acertos (ex: "X de 12 palavras corretas").
- Botão "Reiniciar" para limpar o tabuleiro.

## Tecnologias Utilizadas
- **HTML5**: Estruturação da página, grade do tabuleiro e lista de dicas.
- **CSS3**: Estilização do layout, cores e responsividade.
- **JavaScript**: Lógica de validação das palavras, manipulação do DOM e controle do placar.
